# Toolker Subtitle Companion (Chrome / Edge / Brave Extension)

This extension connects with [toolker.stratom.bond](https://toolker.stratom.bond) to provide **100% authentic YouTube dialogue extraction** directly from your residential IP, completely bypassing Cloudflare datacenter IP restrictions.

---

## 🚀 10-Second Installation

1. Open your browser's extension manager:
   - **Chrome**: `chrome://extensions`
   - **Edge**: `edge://extensions`
   - **Brave**: `brave://extensions`
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked** (top-left).
4. Select this `extension` folder.
5. That's it! When you paste any YouTube video on Toolker, it extracts directly in **under 1 second**.
